Guarded Request

Pick a preset to load a validation case.

How To Use

1. Pick a model
Use `mock-safe-model` first if no upstream model is configured.
2. Pick a preset
Presets cover direct jailbreak, roleplay, obfuscation, multi-turn, and RAG injection.
3. Load and send
Watch `action`, `risk_score`, `input_analysis`, and `context_analysis`.
4. Run smoke suite
This executes the built-in validation suite and prints pass/fail results.

Quick Meaning

`allow`
Benign request passed.
`rewrite`
GuardX forced a safer path for a risky request.
`block`
Request or context was too risky to forward.
`deny_tool`
Agent action was rejected by the sandbox policy.
